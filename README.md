# sales-analysis-dashboard
using powerbi to show case meaningful dashboards and insights
1. Project Overview
This project focuses on analyzing retail sales data and building an interactive dashboard to identify business insights, sales trends, customer behavior, and product performance. The dashboard helps stakeholders make data-driven decisions by visualizing key performance indicators (KPIs) and sales metrics.

2. Objectives
- Analyze overall sales performance
- Identify top-performing products and categories
- Track monthly and yearly revenue trends
- Analyze regional sales distribution
- Monitor profit and customer trends
- Create an interactive dashboard for business decision-making

3.Tools & Technologies Used
- Power BI
- SQL
- Microsoft Excel
- DAX
- Data Cleaning & Transformation

4. Key Features
- Interactive Sales Dashboard
- KPI Cards for:
  - Total Sales
  - Total Profit
  - Total Orders
  - Profit Margin
- Monthly Sales Trend Analysis
- Region-wise Sales Performance
- Category & Sub-category Analysis
- Top Customers & Products
- Dynamic Filters and Slicers

 5.Dataset Information
The dataset contains:
- Order Details
- Customer Information
- Product Categories
- Sales & Profit Data
- Regional Data
- Order Dates
